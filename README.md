# Gurgaon Real Estate EDA

Exploratory Data Analysis of Gurgaon real estate properties using Python, Pandas, and Matplotlib.

## Project Overview

This project analyzes a Gurgaon real estate dataset to understand property prices, localities, property types, BHK configurations, builders, and price per square foot.

The analysis answers important business questions related to the Gurgaon real estate market.

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Git & GitHub

## Business Questions

The analysis explores:

1. Which is the costliest property in the dataset?
2. Which locality has the highest average property price?
3. Which locality has the highest average rate per square foot?
4. Do ready-to-move properties cost more than under-construction properties?
5. Do RERA-approved properties command a price premium?
6. How does area impact property price?
7. Which BHK configuration has the highest average price?
8. Which property type is the costliest?
9. Do certain builders have higher average property prices?
10. Are larger properties always more expensive per square foot?

## Key Analysis

The project uses:

* Data cleaning and preprocessing
* GroupBy analysis
* Average price comparison
* `idxmax()` to identify highest-value categories
* Scatter plots to analyze relationships between numerical variables

## Dataset

The dataset contains Gurgaon real estate property information, including:

* Property price
* Area in square feet
* Rate per square foot
* Locality
* BHK configuration
* Property type
* Builder
* Property status
* RERA approval status

## Conclusion

This project helped analyze real estate pricing patterns in Gurgaon and understand how factors such as locality, property type, BHK configuration, builder, and area can influence property prices.
